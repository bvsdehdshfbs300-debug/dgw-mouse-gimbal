# 03 烧录 ESP32 固件

## 固件目录

推荐使用 ESP-IDF 版本：

```text
firmware_idf/
```

主要源码：

```text
firmware_idf/main/main.c
```

## 烧录命令

打开 ESP-IDF PowerShell，进入目录：

```powershell
cd firmware_idf
```

设置目标芯片：

```powershell
idf.py set-target esp32s3
```

编译、烧录、打开监视器：

```powershell
idf.py -p COM3 build flash monitor
```

如果 `COM3` 不对，换成设备管理器中的实际串口，例如：

```powershell
idf.py -p COM8 build flash monitor
```

## 串口被占用怎么办

如果看到：

```text
Could not open COMx, the port is busy
```

说明串口被其他程序占用。关闭：

```text
idf.py monitor
Arduino 串口监视器
串口助手
Python GUI
```

退出 `idf.py monitor`：

```text
Ctrl + ]
```

## 烧录后手动测试

在 monitor 中输入：

```text
T X 50
T Y 50
M 100 -100
L 1
L 0
```

含义：

```text
T X 50    X 轴慢速测试 50 个脉冲
T Y 50    Y 轴慢速测试 50 个脉冲
M 100 -100 双轴增量移动
L 1       开激光
L 0       关激光
```
