# 06 常见问题

## 电机完全不动

按顺序检查：

```text
1. 电机是否独立上电
2. ESP32 GND 是否和电机 Gnd 共地
3. Stp/Dir 是否接错
4. Com 是否误接，当前方案应不接
5. En 是否误接，当前方案先不接
6. COM 口是否正确
```

先在 monitor 中测试：

```text
T X 50
T Y 50
```

如果电机屏幕 `clk` 变化，说明脉冲进电机了。

## GUI 提示 COM 口拒绝访问

同一个 COM 口只能被一个程序打开。关闭：

```text
idf.py monitor
Arduino 串口监视器
串口助手
其他 Python 程序
```

然后重新连接 GUI。

## X/Y 轴反了

可以：

```text
1. 交换 X/Y 两组线
2. 修改固件 GPIO 定义
```

当前固件默认：

```text
X_STEP = GPIO7
X_DIR  = GPIO15
Y_STEP = GPIO4
Y_DIR  = GPIO5
```

## 方向反了

如果 X+ 实际往 X- 方向动，可以在 GUI 勾选：

```text
X 反向
```

Y 轴同理。

也可以修改固件里的方向电平。

## 电机抖动但不转

可能原因：

```text
1. 脉冲速度太快
2. 电源电流不够
3. 机械负载太大
4. 电机细分太高，看起来转得很小
```

先把 `脉冲半周期 us` 调大：

```text
500
1000
2000
```

## 激光不亮

检查：

```text
1. GPIO6 是否接到激光模块 Signal/IN/S
2. 激光模块 GND 是否接 ESP32 GND
3. 激光模块是否需要单独供电
4. 是否用了高功率激光但没有驱动模块
```

手动发送：

```text
L 1
L 0
```

## Watchdog 报错

早期版本在一次输出大量脉冲时可能触发 watchdog。当前固件已经加入分段让出 CPU。若仍出现，减少单包最大步数或增大脉冲半周期。
