# 05 串口协议

ESP32 固件使用简单 ASCII 文本协议，方便调试和二次开发。

## 串口参数

```text
波特率：115200
换行：\n 或 \r\n
```

## 命令列表

### 单轴移动

```text
X 100
X -100
Y 100
Y -100
```

含义：指定轴按增量步数移动。

### 双轴移动

```text
M 100 -50
```

含义：

```text
X 轴移动 100 个脉冲
Y 轴移动 -50 个脉冲
```

### 慢速测试

```text
T X 50
T Y 50
```

用于检查接线。脉冲很慢，便于观察电机屏幕 `clk` 是否变化。

### 设置速度

```text
P 500
```

`P` 是脉冲半周期，单位微秒。

```text
P 500 约等于 1000 脉冲/秒
P 250 约等于 2000 脉冲/秒
```

数值越小，速度越快。太小可能丢步或电机响应不稳。

### 激光开关

```text
L 1
L 0
L T
```

含义：

```text
L 1 -> 开激光
L 0 -> 关激光
L T -> 切换激光状态
```

### 帮助

```text
?
```

## 控制方式说明

本项目采用增量式控制：

```text
每条运动命令 = 从当前位置再移动多少步
```

不是绝对坐标控制：

```text
不是移动到 X=1000, Y=500
```
