# 开源发布说明

## 项目名称

ESP32-S3 双轴鼠标云台

## 简介

本项目使用 ESP32-S3 控制两台 ZDT X42S 闭环步进电机，实现双轴云台的鼠标控制、点动控制和激光开关控制。上位机使用 Python Tkinter 编写，固件使用 ESP-IDF 编写。

发布目标是让没有经验的新手也能按文档完成：

```text
接线
烧录
运行 GUI
手动测试
排查常见问题
```

## 安全提示

- 电机必须使用独立电源供电。
- ESP32-S3 只能输出控制信号，不能给电机供电。
- 激光模块应注意人眼安全。
- 高功率激光不要直接由 GPIO 驱动。
