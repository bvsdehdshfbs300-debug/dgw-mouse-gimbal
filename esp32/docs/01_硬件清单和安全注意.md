# 01 硬件清单和安全注意

## 必需硬件

```text
ESP32-S3 开发板 x1
ZDT X42S 闭环步进电机 x2
10-29V 电机电源 x1
USB 数据线 x1
杜邦线若干
Windows 电脑 x1
```

## 电源建议

单台 X42S 建议电源能力不低于 3A。两台电机同时使用时，建议：

```text
10-29V
>= 6A
```

## 安全注意

```text
1. ESP32 不能给电机供电，只能输出控制信号。
2. 电机电源正负极不要接反。
3. ESP32 GND 必须和电机 Gnd 共地。
4. 激光模块注意人眼安全，不要直射眼睛。
5. 大功率激光不要直接接 GPIO，必须使用驱动模块。
6. 调试时先低速、小步数测试。
```

## 逻辑电平

X42S 的 `Stp/Dir` 支持 `3.3-24V` 输入，所以 ESP32-S3 的 `3.3V GPIO` 可以直接控制。

当前项目使用单端脉冲接法：

```text
Com 不接
Stp 接 GPIO
Dir 接 GPIO
Gnd 共地
```
