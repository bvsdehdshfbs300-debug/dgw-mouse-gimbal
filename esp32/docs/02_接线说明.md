# 02 接线说明

## 总体原则

```text
ESP32-S3 只负责控制信号
电机必须使用独立电源
ESP32 GND 必须和电机 Gnd、电源负极连接在一起
```

## X 轴接线

```text
ESP32 GPIO7  -> X 电机 Stp
ESP32 GPIO15 -> X 电机 Dir
ESP32 GND    -> X 电机 Gnd
```

## Y 轴接线

```text
ESP32 GPIO4 -> Y 电机 Stp
ESP32 GPIO5 -> Y 电机 Dir
ESP32 GND   -> Y 电机 Gnd
```

## 激光接线

```text
ESP32 GPIO6 -> 激光模块 Signal / IN / S
ESP32 GND   -> 激光模块 GND
```

如果激光模块只有正负极，不要直接接 GPIO。应使用 MOSFET/三极管模块控制。

## 电机供电

```text
外部电源 + -> 两个电机 V+
外部电源 - -> 两个电机 Gnd
ESP32 GND   -> 外部电源 -
```

## 不接的线

当前方案中：

```text
电机 Com -> 不接
电机 En  -> 不接
```

`En` 可能因为电机菜单配置不同导致高低电平含义相反。为了减少新手出错，当前固件默认不依赖 `En`。

## 如果 X/Y 轴反了怎么办

有两种方法：

```text
1. 交换 X/Y 两组 Stp/Dir 线
2. 修改固件里的 GPIO 定义
```

当前固件已经按项目实际接线做过一次 X/Y 软件交换。
