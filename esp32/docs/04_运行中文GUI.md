# 04 运行中文 GUI

## 安装依赖

在项目根目录执行：

```powershell
pip install -r requirements.txt
```

## 启动 GUI

```powershell
python pc\mouse_gui.py
```

## 使用步骤

```text
1. 选择 ESP32 的 COM 口
2. 点击“连接”
3. 用点动按钮测试 X/Y 轴
4. 调整“脉冲半周期 us”
5. 调整“灵敏度 步/像素”
6. 勾选“启用鼠标输出”
7. 在右侧轨迹画布中移动鼠标
```

## 参数解释

```text
灵敏度 步/像素：
鼠标移动 1 个像素对应多少电机脉冲。

死区 像素：
忽略很小的鼠标抖动。

单包最大步数：
每次最多发送多少步，数值越大响应越猛。

脉冲半周期 us：
ESP32 输出脉冲的半周期。数值越小，电机越快。

点动步数：
点击或按住点动按钮时，每次发送多少步。
```

## 推荐初始参数

```text
灵敏度：0.2
死区：0
单包最大步数：40
脉冲半周期：500
点动步数：100
```

## 注意

GUI 和 `idf.py monitor` 不能同时打开同一个 COM 口。
