# ESP32-S3 双轴鼠标云台备份

本文档记录当前可工作的接线、供电、固件协议和运行方式。

## 硬件

- 主控：ESP32-S3 N16R8
- 电机：张大头 / ZDT X42S 第二代闭环步进电机，两台
- 控制方式：`Stp/Dir` 单端脉冲方向控制
- 上位机：Windows Python GUI，通过 USB 串口发送文本命令

## 当前接线

固件里已经把 X/Y 轴做了软件交换，以下为当前逻辑轴接线。

### X 轴

```text
ESP32-S3 GND    -> X 电机 Gnd
ESP32-S3 GPIO7  -> X 电机 Stp
ESP32-S3 GPIO15 -> X 电机 Dir
```

### Y 轴

```text
ESP32-S3 GND   -> Y 电机 Gnd
ESP32-S3 GPIO4 -> Y 电机 Stp
ESP32-S3 GPIO5 -> Y 电机 Dir
```

### 激光灯

```text
ESP32-S3 GPIO6 -> 激光模块 Signal / IN / S
ESP32-S3 GND   -> 激光模块 GND
```

注意：`GPIO6` 已复用为激光控制脚，不再接 Y 电机 `En`。

### 不接的引脚

```text
电机 Com -> 不接
电机 En  -> 当前方案不接
```

## 供电

```text
外部电源 + -> 两个电机 V+
外部电源 - -> 两个电机 Gnd
ESP32-S3 GND -> 外部电源 - / 两个电机 Gnd
```

建议电源：

```text
10-29V
两台电机建议 >= 6A
```

不要用 ESP32-S3 给电机供电。ESP32 只输出控制信号。

激光模块如果电流较大，不要直接由 GPIO 带负载，应使用带驱动的激光模块或 MOSFET/三极管开关模块。

## 固件

ESP-IDF 工程：

```text
.\firmware_idf
```

主要文件：

```text
firmware_idf/main/main.c
```

烧录：

```powershell
cd .\firmware_idf
idf.py set-target esp32s3
idf.py -p COM3 build flash monitor
```

如果 `COM3` 被占用或不可用，尝试：

```powershell
idf.py -p COM8 build flash monitor
```

退出 monitor：

```text
Ctrl + ]
```

## 串口协议

波特率：

```text
115200
```

命令为 ASCII 文本，以换行结束。

### 单轴运动

```text
X 100
X -100
Y 100
Y -100
```

正负号决定方向。

### 双轴运动

```text
M 50 -30
```

含义：X 轴走 `50` 个脉冲，Y 轴走 `-30` 个脉冲。固件会交织输出两轴脉冲。

### 慢速测试

```text
T X 20
T Y 20
```

用于检查接线。脉冲很慢，方便看电机屏幕 `clk` 是否变化。

### 设置速度

```text
P 500
```

`P` 是脉冲半周期，单位微秒。`P 500` 约等于 `1000` 脉冲/秒。数值越小越快。

### 激光灯

```text
L 1
L 0
L T
```

含义：

```text
L 1 -> 开激光
L 0 -> 关激光
L T -> 切换激光状态
```

### 帮助

```text
?
```

## PC GUI

GUI 文件：

```text
.\pc\mouse_gui.py
```

运行：

```powershell
python .\pc\mouse_gui.py
```

使用注意：

- GUI 连接串口前要关闭 `idf.py monitor`
- Windows 同一个 COM 口只能被一个程序打开
- GUI 中点动按钮支持按住连续运动
- 鼠标只在右侧轨迹画布内移动时才控制电机
- 右键画布可清除轨迹

## 当前 GPIO 定义

```text
逻辑 X_STEP = GPIO7
逻辑 X_DIR  = GPIO15
逻辑 Y_STEP = GPIO4
逻辑 Y_DIR  = GPIO5
LASER      = GPIO6
```

## 故障排查

电机不动时按顺序查：

1. ESP32 `GND` 是否和电机 `Gnd` 共地
2. `Stp` 是否接到了正确 GPIO
3. 电机 `Com` 是否误接，当前方案应不接
4. `En` 是否误接导致禁用，当前方案先不接
5. 用 `T X 20` / `T Y 20` 看电机屏幕 `clk` 是否变化
6. `idf.py monitor` 是否占用了 GUI 要连接的 COM 口
